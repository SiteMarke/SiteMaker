# sitemaker 3.0 — как всё устроено

Папка `_tools` не публикуется на сайте (GitHub Pages пропускает папки, начинающиеся с `_`).

## Файлы сайта

| Что | Где |
|---|---|
| Главная (RU) | `index.html` + `css/main.css` + `js/main.js` |
| Главная (KZ) | `kz/index.html` — собирается из `index.html` скриптом `make_kz.py` |
| Казахские тексты данных и соглашение | `js/i18n-kk.js` |
| Данные (цены, работы, FAQ) | сервер (админка `/admin.html`), запасная копия — `data/site.json` |
| Аналитика | `js/analytics.js` — впишите ID в `CFG` |
| Консультант | `js/consult.js` — сценарии; для настоящего AI впишите адрес сервера в `CFG.api` |
| Страницы услуг, городов, портфолио, блог | генерируются `build_pages.py` из `content_*.py` |
| Стили внутренних страниц | `css/page.css` |

## Пересборка

```
python3 _tools/build_pages.py   # услуги, города, /uslugi/, портфолио (RU/KZ), блог, 404, sitemap.xml, robots.txt, js/cases.js
python3 _tools/make_kz.py       # /kz/index.html после правок русской главной
```

`make_kz.py` останавливается, если какой-то русский фрагмент главной изменился, и показывает его — добавьте новый перевод в список замен.

## Цены новых опций калькулятора

По умолчанию (в `js/main.js`, функция `ext()`):

- уникальный дизайн — +5 000 ₸ (в «премиуме» входит);
- онлайн-оплата картой — +5 000 ₸ (в интернет-магазине и «премиуме» входит);
- пакет «сайт + Telegram-бот» — бот со скидкой 20%;
- пакет «сайт + настройка рекламы» — +5 000 ₸;
- хостинг после 3 месяцев — от 1 000 ₸/мес.

Поменять можно в `ext()` или добавить в данные `calc.ext = { "uniq": 5000, "card": 5000, "botPct": 20, "ads": 5000, "hostMonth": 1000 }`.
Стиль и анимации — без доплаты (по акции «все доп. опции бесплатно»). Без выбранных новых опций итог считается по старой формуле.

## Ручные настройки

1. **Google Analytics 4 / Яндекс Метрика**: ID в `js/analytics.js`. Цели: `lead_submit`, `generate_lead`, `click_whatsapp`, `click_telegram`, `calc_start`, `calc_pdf`, `calc_send`, `portfolio_open`.
2. **Search Console / Вебмастер**: подтверждения уже лежат в корне. Отправьте `https://sitemakerkz.com/sitemap.xml` в обе системы.
3. **Ссылки на кейсы**: новые работы из админки появятся в портфолио после `build_pages.py` (до этого — без страницы кейса, но на главной видны).
